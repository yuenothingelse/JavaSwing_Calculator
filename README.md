# Calculator Java

A simple calculator application built with **Java Swing**.
This project provides basic mathematical operations with a clean and simple user interface.

## Features

| Feature             | Description                  |
| ------------------- | ---------------------------- |
| Addition            | `+`                          |
| Subtraction         | `−`                          |
| Multiplication      | `×`                          |
| Division            | `÷`                          |
| Percentage          | Calculate percentage values  |
| Positive / Negative | Change number sign           |
| Backspace           | Delete the last digit        |
| Clear               | Reset calculator             |
| Keyboard            | Basic keyboard input support |
| UI                  | Rounded calculator buttons   |

## Percentage

The percentage calculation uses:

```text
First Number × Percentage ÷ 100
```

Example:

```text
100 % 1 = 1
500 % 20 = 100
```

## Technologies

| Technology | Usage                    |
| ---------- | ------------------------ |
| Java       | Programming language     |
| Java Swing | Graphical User Interface |
| AWT        | UI components and events |

## Run

Compile the program:

```bash
javac SwingCalculator.java
```

Run:

```bash
java SwingCalculator
```
